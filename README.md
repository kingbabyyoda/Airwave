# 🎧 Airwave Lite

Airwave Lite is a simple web platform that lets users create their own music stations, upload songs, organize playlists, and share a public page where others can listen.

---

## Features

### Accounts
- User registration and login
- Secure authentication
- Personal dashboard

### Stations
- Create custom music stations
- Add name, description, genre, and logo
- Public station pages with shareable links

### Music Uploads
- Upload MP3, WAV, FLAC files
- Automatic metadata storage
- Station-based music libraries

### Playlists
- Create multiple playlists per station
- Add/remove/reorder songs
- Organize music for different moods or themes

### Music Player
- Built-in browser audio player
- Stream songs from station playlists
- Simple queue-based playback

### Public Sharing
- Each station gets a public URL
- Anyone can listen without logging in
